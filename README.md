# Git Airlock Scoop bucket

```powershell
scoop bucket add git-airlock https://github.com/erikibolya/scoop-git-airlock
scoop install git-airlock/git-airlock
```

The bucket installs the `airlock` CLI. Use the Windows installer from the
[releases](https://github.com/erikibolya/git-airlock/releases) for the desktop
dashboard and the scheduled worker.
